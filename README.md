# TD385 mini app

The Telegram mini app of a private, **paper-trading** research bot: one static page
(`index.html`) and this README. Nothing else belongs in this repository.

- **No data and no keys here.** The page holds only the bot's settings schema (names,
  bounds, steps, labels), so its steppers know every limit.
- **The data travels in the link's fragment** (`#s=...`): a compressed snapshot the bot
  puts after the `#` of the button's URL. Browsers never send a fragment to the server, so
  this host only ever sees a request for the empty page.
- **No server, no network calls.** The only external script is Telegram's own
  `telegram-web-app.js`, which Telegram requires; a Content-Security-Policy allows nothing
  else to run. Every value is rendered as text, never as markup.
- **Changes go back through Telegram**, as a short `/start` payload (or `sendData`) that the
  bot checks against the same bounds, and the trading engine checks again. The page cannot
  change anything by itself: a pause, a resume or closing positions is confirmed in the chat.

Generated by `uv run python -m td385.meme.miniapp build --out DIR` in the private repo;
do not edit `index.html` by hand.
